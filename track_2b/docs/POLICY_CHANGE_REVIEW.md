# Compare two reviewed policies

This package includes the current policy-impact browser panel, fixed computation modules, report renderer and CLI as exact copied source. The panel compares complete declared request profiles, shows affected target/property rules and retains unknown slots. A nearby unchanged profile applies only to named rules, not whole-form correctness or actual affected people.

The source-authored equipment-delivery example explicitly declares agent-simulation approvals. It is neither Apertus output nor human review. The revision removes unloading assistance for courier/heavy deliveries with a loading dock; the unresolved access-instructions slot stays unknown. Finite scenarios are illustrative inputs, not observed requests.

On a separately provisioned Node 24 system with the locked dependency installed:

```sh
cd track_2b
node src/policy-change-cli.mjs demo /absolute/existing-parent/fresh-report.html
node src/policy-change-cli.mjs compare OLD_SPEC.json NEW_SPEC.json CURRENT_FORM.json /absolute/existing-parent/fresh-report.html
```

The output must be new. Exit 1 means known changes, 3 means no known changes with unresolved slots, 0 means no known changes and no unknown slots, and 2 means failure. These are documented commands; the packaging task did not execute product modules, real workers or browser code.
